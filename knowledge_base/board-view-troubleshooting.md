# Troubleshoot the board view

If the board view freezes, crashes, or shows cards in the wrong column, try these in order.

1. Refresh the page. The board reloads from the server and fixes most display glitches.
2. Clear the active filter. Dragging a card into a column hidden by a filter used to fail on older builds, and the filter bar shows a count of hidden cards.
3. Disable browser extensions that modify pages, such as dark mode or translation tools.
4. Try a private window or another browser.

## Collect details for support

If the problem persists, send us:

- The browser and version.
- The project name and the exact steps that lead to the crash.
- A screenshot or short screen recording.
- Any red error text shown at the bottom of the page.

Large boards with more than 2,000 cards load slowly. Archive finished cards to speed them up.
