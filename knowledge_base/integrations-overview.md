# Integrations overview

Install integrations from **Settings > Integrations**. Admins and owners can add them.

## Available now

- **Google Calendar**: shows due dates and milestones in a calendar feed that you can subscribe to, and syncs in both directions for tasks assigned to you.
- **Slack**: posts status changes and mentions to a channel. You pick the project and the events.
- **GitHub and GitLab**: link pull requests and commits to tasks by including the task key in the title.
- **Zapier and webhooks**: for everything else.

## Not available yet

A native Microsoft Teams integration and a Jira two-way sync are on the roadmap. Until then you can use webhooks or Zapier.

## Permissions

An integration acts with the permissions of the admin that installed it. Remove it when that admin leaves the company. See [API tokens](api-tokens.md).
