# File upload limits

| Plan | Largest single file |
| --- | --- |
| Free | 10 MB |
| Team | 100 MB |
| Business | 1 GB |

## Upload fails with a generic error

- Check the file size against your plan limit.
- Check that the workspace has storage left under **Settings > Usage**. When storage is full, every upload fails with the same error.
- Corporate proxies sometimes cut uploads over 20 MB. Try from another network.

## Blocked file types

Executable files such as .exe, .bat and .msi are blocked. Put them in a zip file or share a link instead.

You can buy a storage pack from **Settings > Billing > Add-ons**. See [Add-on orders and their status](add-on-orders.md).
