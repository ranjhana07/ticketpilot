# Roles and permissions

Loomwork has four roles.

| Role | Can do |
| --- | --- |
| Owner | Everything, including billing, deleting the workspace and transferring ownership |
| Admin | Manage members, projects, integrations and security settings |
| Member | Create and edit projects and tasks |
| Guest | Work only in projects they were invited to, and does not use a seat |

## Change a role

Owners and admins can change roles from **Settings > Members**. A workspace needs at least one owner. To transfer ownership, the current owner chooses **Make owner** next to another member.

## Project permissions

Projects can be private. A private project is visible only to the people added to it, even if they are admins. Owners can always restore access by adding themselves.

Business plan workspaces can create custom roles that limit who can export data or manage integrations.
