# Set up two-factor authentication

Two-factor authentication (2FA) asks for a six digit code in addition to your password.

## Turn it on

1. Go to **Profile > Security**.
2. Select **Enable two-factor authentication**.
3. Scan the QR code with an authenticator app such as 1Password, Authy or Google Authenticator.
4. Enter the six digit code to confirm.
5. Save the ten recovery codes somewhere safe. Each code works once.

## Requiring it for a workspace

Business plan owners can require 2FA for every member under **Settings > Security > Require 2FA**. Members without 2FA are asked to set it up at their next sign-in.

## Good to know

- SMS codes are not supported.
- Codes depend on your device clock. If codes are rejected, turn on automatic time on your phone.
- Recovery codes are shown only once. You can generate a new set from the same page, which invalidates the old one.
